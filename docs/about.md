# About MW Cast

## Who maintains it

MW Cast is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/mwcast](https://github.com/mediuswareltd/mwcast).

## Why it exists

A high-performance live streaming platform with React frontend, Rust API, Kafka chat, and MediaMTX ingestion.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.

## Documentation

- Docs site: https://mediuswareltd.github.io/mwcast/
- Getting started, guide, and about pages are generated from the project README and kept next to the code under `docs/`.
