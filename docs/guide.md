# Guide

## What it is

A high-performance live streaming platform with React frontend, Rust API, Kafka chat, and MediaMTX ingestion.

## Stack

`React`, `Rust`, `Kafka`, `MediaMTX`, `PostgreSQL`

## Capabilities

### Host live streams

Share unique URLs and broadcast to viewers.

### Realtime chat

Kafka-backed chat per stream.

### MediaMTX pipeline

RTMP ingest with HLS and WebRTC playback.

### Full stack

React UI, Rust API, Docker Compose infra.
