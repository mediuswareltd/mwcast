# Getting started

Install and run **MW Cast** locally.

## Prerequisites

- Working knowledge of JavaScript / Rust
- Git and a terminal

## Install

```bash
git clone https://github.com/mediuswareltd/mwcast.git
cd mwcast
# see README for frontend + API + compose setup
```

## Quick start

```bash
docker compose up -d
# start API and frontend per README
```
